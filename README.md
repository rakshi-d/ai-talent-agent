##  How to Run This Project

This project is a simple AI-based talent scouting system that runs locally.

### Step 1: Download the Project
Clone the repository to your system:

git clone <your-repo-link>

### Step 2: Go to Backend Folder
cd ai-talent-agent/backend

### Step 3: Install Required Libraries
Make sure Python is installed, then run:

pip install flask flask-cors

### Step 4: Start the Server
Run the backend using:

python app.py

You should see a message like:
Running on http://127.0.0.1:5000

### Step 5: Open the Frontend
Go to the frontend folder and open:

frontend/index.html

You can just double-click it to open in your browser.

### Step 6: Use the Application
Enter a job description, click the button, and you will see a ranked list of candidates based on match and interest.
